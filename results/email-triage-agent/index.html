Email Triage Agent

A persistent agent that sorts high-volume Outlook inboxes automatically and rescues legitimate mail from junk.

50 emails triaged in 13s, down from 8 minutesAutonomous inbox management.

The problem

High-volume Outlook inboxes needed constant manual sorting, and legitimate contacts occasionally landed in junk unseen.

What we built

A persistent Python agent that authenticates to Microsoft Graph (MSAL device-code flow, cached token), applies sender rules first, then batch-classifies the rest with an LLM into Actionable, Automated and Spam, moves messages to the right folders, and rescues protected contacts from junk. It was replicated across multiple staff inboxes from a reusable build prompt.

What changed

Triage of 50 emails went from roughly 8 minutes to about 13 seconds.

The stack

  • Python
  • Microsoft Graph API
  • MSAL
  • Anthropic API
  • Local JSON classification cache
  • Continuous polling service
