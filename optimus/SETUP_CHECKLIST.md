# Optimus setup checklist

Work in progress. This file is completed at the end of the build. Steps found so far:

- [ ] Deploy the proxy (Cloudflare account, `ANTHROPIC_API_KEY`, `APP_TOKEN`). See `proxy/README.md`.
- [ ] Create an Expo account and run the EAS build.
- [ ] Google Cloud OAuth client for Gmail.
- [ ] Microsoft app registration for Outlook.
- [ ] Phone: turn off Auto Blocker, install the APK, set battery to Unrestricted, allow restricted settings, grant notification access.
